# Signal Quality Improvement — Phase 1.5

PM กำหนดเป้าหมายย่อยให้ god-port/broky ปรับปรุง signal quality

## ลำดับการทำงาน

### Step 1: S4 — Tune confidence threshold (quickest win)
- รัน `python scripts/threshold_scan.py` หรือ manual sweep ที่ min_confidence = 0.40, 0.45, 0.50, 0.55, 0.60
- เป้า: หา threshold ที่ให้ PF ≥ 1.5, WR ≥ 50%, และ trade frequency ≥ 30/year
- KPI: threshold อยู่ในช่วง 0.45-0.55

### Step 2: S5 — Enable multi-timeframe confirmation
- code มี d1_trend parameter อยู่แล้วใน generator.py — เปิดใช้ใน backtest
- เป้า: MTF filter active, WR ≥ 50% with filter on
- KPI: D1 trend alignment check ทำงานในทุก signal

### Step 3: S1 — Reduce false BUYs in choppy markets
- ปรับ Bollinger + ADX interaction: เมื่อ ADX 20-25 (trend forming) ให้ Bollinger weight ลดลง
- เป้า: WR จาก 44% → 50%+
- KPI: False signal rate ลดลง (WR เพิ่มขึ้น)

### Step 4: S6 — Market regime detection
- เพิ่ม regime classifier: trending / ranging / volatile
- เมื่อ ranging → HOLD (ไม่เทรด), trending → normal signals, volatile → reduced position
- KPI: Regime label อยู่ใน signal output

### Step 5: S7 — Session-aware filtering
- เปิด session multiplier: Asian = 0.85 (ลด confidence), Overlap = 1.1 (เพิ่ม)
- KPI: Asian session WR ดีขึ้น หรือ filtered ออก

### Step 6: S8 — Final validation
- รัน full backtest ด้วยทุกการปรับปรุง
- **ต้องผ่านพร้อมกัน**: PF ≥ 1.5, MaxDD ≤ 20%, WR ≥ 55%, ≥ 30 trades/year

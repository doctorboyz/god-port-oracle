## Lessons Learned

- **Monitor ใหม่ควรถูก validate ด้วยการใช้งานจริงทันที** — snapshot จับ zombie ในวันแรก, watchdog จับ PATH bug ใน fire แรก; ทั้งสองพิสูจน์คุณค่าเร็วกว่า test suite
- **launchd PATH ไม่มี /usr/local/bin** — binary ที่เรียกจาก agent ต้อง resolve absolute; `shutil.which() or "/usr/local/bin/..."` เป็น pattern ที่ใช้ซ้ำได้ (ดู learning 2026-09-30 เรื่อง crontab ด้วย)
- **ความคาดหวังใน test ต้องมาจากสูตรที่อ่านจริง ไม่ใช่ความจำ**
- **การลบ data ที่โดนสร้างซ้ำ = ต้องแก้ producer ก่อน consumer cleanup เสมอ**

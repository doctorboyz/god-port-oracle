# Retro 2026-10-10 — แก้ margin gate env no-op + ปิด gap คลาส compose-env-no-op + บันทึก investment config

**Trigger**: คุณหมอสั่งผ่าน Hermes — Hermes daily check พบจาก log จริงว่า
`trade_blocker:margin_safety` บล็อกสัญญาณจริง ~310 ครั้ง (6-9 ต.ค.) ทั้งที่ผ่าน
gate อื่นหมด

## เกิดอะไรขึ้น (root cause — verify จากโค้ดจริง ตรงตาม Hermes รายงาน)

- `live_trader.py` อ่าน `MT5_LEVERAGE_{account}` (default 100) **สองจุด**
  (gate 6b entry + scale-in margin) และ `m5_scalp_trader.py` อีก **จุด** ที่สาม
- compose ตั้งแค่ `LEVERAGE_P*=2000` (ชื่อเดียวกับที่ registry อ่าน) → env ที่ตั้ง
  ไม่มีผู้อ่าน / ชื่อที่อ่านไม่มีใครตั้ง = **no-op เงียบ** ไม่ error ไม่ warning
- ผล: margin คิดที่ 1:100 → ไม้ 0.01 lot ที่ทอง $4,220 = $42.20 ทับ free_margin
  ~$47.80 → บล็อก (threshold 0.80) · baseline จริงจาก DB: **310 ครั้ง**
  (5 ต.ค. 4 / 6 ต.ค. 78 / 7 ต.ค. 94 / 8 ต.ค. 48 / 9 ต.ค. 86) · ไม้เปิดต่อวัน
  ตกจาก 12 → 1-2 ไม้
- แก้ที่ 1:2000 แล้ว margin = **$2.11/ไม้** (หมายเหตุ: คุณหมอประเมินไว้ ~$0.21
  — ตัวเลขจริงตามสูตร $2.11 ยังเหลือเป้าอย่างมาก)

## แก้อะไร

1. **Helper `get_account_leverage()`** ใน `metty/core/account_registry.py` —
   ชื่อเดียวกับที่ registry/compose ใช้ (`LEVERAGE_{name}`) + registry ตัวเอง
   ก็เรียกใช้ → หัวเดียว ไม่มีหัวที่สองให้ drift อีก · แทนที่ 3 จุดอ่าน
   (live_trader ×2 + m5_scalp_trader ×1)
2. **Guard test `tests/test_env_coverage_guard.py`** ปิด gap เชิงระบบ:
   - ทิศ compose→code: env ทุกตัว (255 ชื่อ) ที่ farm compose เขียนลง container
     ต้องมีผู้อ่านจริง — ผ่าน (0 ตาย)
   - ทิศ code→config: per-account read ทุกตระกูล (f-string template + _A.._D/_P*)
     ต้องมีสมาชิกถูก set จริงใน config ใดๆ หรืออยู่ใน allowlist พร้อมเหตุผล —
     พิสูจน์เขี้ยวแล้ว: `MT5_LEVERAGE` (ตระกูลที่เพิ่งลบ) ถูกจับ → pre-fix test
     ต้อง FAIL จริง
3. **Causal test `tests/test_leverage_env_farm_causal.py`** — RED 4 (บล็อก
   `margin $42.20 > 80% of free margin $47.80` เป๊ะข้อความจากเหตุการณ์จริง +
   helper ยังไม่มี) → GREEN 8 รวม controls 3 (LEVERAGE=100 ชัดๆ ยังบล็อก /
   ไม่ set env ยังบล็อกที่ default / env พัง fallback ปลอดภัย)

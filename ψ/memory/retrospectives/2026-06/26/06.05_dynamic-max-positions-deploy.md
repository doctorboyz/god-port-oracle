## Key Code Changes

**Dynamic formula** (same in both traders):
```python
def _calculate_max_positions(self, equity: float) -> int:
    if equity <= 0:
        return 1
    calculated = int(equity // self._equity_per_position)
    return max(1, min(self._max_positions_cap, calculated))
```

**Position limit check** (was static, now dynamic):
```python
# Before: if len(open_trades) >= self.max_positions:
# After:
current_equity = self._get_balance()

if len(open_trades) >= dynamic_max:
```

## Architecture Decisions

1. **$200 equity_per_position** — Chosen because XAUUSD 0.01 lot needs ~$8 margin + ~$20-30 SL risk + buffer. $200 per position is conservative but safe for $199 account.
2. **Cap of 5** — Even with large equity, no more than 5 simultaneous positions. Prevents the 18-position margin call that happened June 22.
3. **Minimum 1** — Always allow at least 1 position so trading never completely stops.
4. **Floor division** — `int(equity // 200)` means $399 → 1 position, $400 → 2. Conservative bias.

If MT5 is down AND the variable isn't set, we fall back to `initial_balance` which could be stale. The M5ScalpTrader uses `self._get_balance()` directly which is cleaner.

## Lessons Learned

- **Dynamic position limits prevent margin calls** — The June 22 incident (18 positions on $199) happened because `max_positions=5` was static. Dynamic limits scale with account size: small account = 1 position, growing account = more positions. This is fundamentally safer.
- **Floor division is conservative** — `equity // 200` rounds down, so $399 → 1 position, not 2. This is the right bias for risk management. You'd rather have too few positions than too many.

## Lessons Learned

- Bridge MT5 ของเราเป็น raw socket protocol — `curl /health` ไม่ตอบแม้บน mt5a
  production ที่ทำงานปกติ. healthcheck ที่ถูกคือ socket connect (แบบที่ compose
  ตั้งไว้แล้ว) ไม่ใช่ HTTP probe
- MT5 container first boot: wine + Python install ใช้ ~10 นาที ก่อน bridge จะ listen —
  "unhealthy" ช่วงนี้เป็นเรื่องปกติ อย่ารีบ restart
- PreToolUse hook `block-co-authored-trailer.js` บล็อก Co-Authored-By trailer จริงจัง
  (exit 2) — commit ของ repo นี้ห้ามมี trailer ตาม ISSUE-148/167
- บทเรียน deploy ที่ generalize ได้: จด baseline ก่อน + verify หลัง = วิธีเดียวที่
  พิสูจน์ "ไม่โดนแตะ" ได้จริง (คำสัญญาปากเปล่าหรือ "ไม่ได้แตะไฟล์นั้น" ไม่พอ)

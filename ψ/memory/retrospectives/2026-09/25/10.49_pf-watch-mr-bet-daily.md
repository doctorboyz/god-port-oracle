## Honest Feedback (จุดที่ต้องยอมรับ)

1. **ครั้งแรกผมเผลอจะสรุปว่า "ssh พัง"** ทั้งที่สาเหตุจริงคือคำสั่งผมเอง — ความระวัง "ถ้าอะไรไม่มี output ให้ตรวจคำสั่งก่อนตรวจระบบ" ยังไม่เป็น reflex ของผม
2. **เกณฑ์ anomaly บางข้อตรวจได้แค่หยาบๆ** — ผมบอกว่า "balance ไม่ลดเกิน 5%/วัน" ทั้งที่จริงๆ ไม่มีข้อมูล balance เมื่อวานในมือ ผมใช้ proxy โดยไม่บอกคุณหมอตรงๆ ว่าเกณฑ์นี้ตรวจจริงไม่ได้ใน session เดียว ควรเก็บ balance รายวันเป็นตารางเทียบได้
3. **ระบบเฝ้ารายวันพึ่ง session ที่เปิดอยู่** — ผมสร้าง cron ไว้ session ก่อนหน้า แต่ session ใหม่ cron หายหมด และผมไม่ได้ตรวจว่า cron ยังอยู่ไหมใน session นี้ นี่คือช่องโหว่ที่ผมรู้แต่ไม่ได้ทำอะไรกับมัน

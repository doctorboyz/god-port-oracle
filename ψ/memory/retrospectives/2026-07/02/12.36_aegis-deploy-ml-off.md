## Lessons Learned

1. **"No trades" is not a single diagnosis.** It's a chain: signal generation → ML filter → reversal gate → counter-trend penalty → confidence threshold → lot sizing → broker min. Each gate can be the blocker. Diagnose by counting rejections per gate, not by guessing.

2. **Local backtest and live deploy are not the same artifact.** Local MC = AEGIS only. Live demo (before today) = AEGIS + ML filter. Comparing PF from one to 0-trades in the other is a category error. Always state which gates are active when reporting a result.

3. **One config change + restart is the cleanest causation proof.** When "system not trading," disable the suspected gate, restart, watch. If a trade opens in 60 seconds, that gate was the blocker. Faster than hours of log archaeology.

4. **Signal_group per account is a design pattern, not a bug.** B=volume, C=ob_os, D=ma. Each account is a different signal source on the same market. They will not trade in sync. Stop expecting them to.

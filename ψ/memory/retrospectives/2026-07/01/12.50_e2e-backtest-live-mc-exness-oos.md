## Lessons Learned

1. **DP daily_start_equity = peak_equity ทำให้ daily limit โตตาม equity** — กลยุทธ์ profitable มากจะไม่ trigger daily drawdown เพราะ limit ขยายตาม peak. ไม่ใช่ bug เป็น design. แต่ถ้าต้องการให้ DP ทำงานเสมอ ต้อง peg กับ initial_equity ไม่ใช่ peak

2. **OOS validation ดีแค่ไหนขึ้นกับขนาดข้อมูล** — 2.5 เดือนสั้นเกินไปสำหรับ deploy decision. ใช้เป็น signal ว่า "กลยุทธ์ไม่ break" ได้ แต่ใช้เป็น evidence ว่า "พร้อม deploy" ไม่ได้

3. **Mirror pattern ช่วย fix เร็ว** — DP set_time fix ใช้แบบเดียวกับ CircuitBreaker เลย เพราะเคยทำให้ CB แล้ว. ถ้ามี pattern เดิมในระบบ ใช้มันก่อน ไม่ต้องคิดใหม่

4. **รายงานภาษาธรรมดามีค่า** — user ขอ "ไม่ใช้ศัพท์เทคนิค ไม่ใช้ตัวย่อ" ทำให้ผมต้องแปลง PF/WR/MaxDD เป็นภาษาเข้าใจได้. ผมควรทำแบบนี้บ่อยขึ้น ไม่ใช่แค่ตอน user ขอ
